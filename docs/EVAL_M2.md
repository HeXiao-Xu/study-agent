## 4. 失败与解释

### 4.1 自动拒答准确率 82.5%，不是回复“答了题”

7 条未命中的应拒题（q031、q034–q038、q040）由查询改写的 `chitchat` 分支处理，回复明确说“不属于学习内容 / 无法获取实时信息 / 只处理学习问题”，但没有进入 `prepare_answer` 的拒答分支，所以 `done.refused=false`、`refusal_reason=null`。

这不是“模型把天气题答成数学题”，而是产品语义：

- `refused=true` 目前表示“RAG 无依据/低分拒答”；
- chitchat 的“礼貌拒绝”不置 `refused`；
- 评测按 `done.refused` 计算，故自动指标 82.5%；人工按“是否给出实质答案”判 10/10。

后续如果要把“非学习问题拒绝”也纳入统一拒答语义，应改查询改写/问答状态机，而不是改评测脚本把 82.5% 粉饰成 100%。

### 4.2 引用精确率 0.897

- 大多数题只引 1–2 个块，且都在 gold 内；
- q001、q009、q010 多引了同类题/步骤块，人工看能支撑断言；
- q028 正文写“本题未使用参考资料 [2]–[6]”，正则把 `[2]`、`[6]` 当成正文引用，额外计入 262/285，是解析噪声。
- gold 只标 1 个块，导致“多引相关块”会被精确率惩罚；这是指标口径限制，不代表引用错误。

### 4.3 内容风险（非指标）

- q014：按题面严格定义，四个选项都不满足“像落在 B 中”，回答判“均不构成”；常见教学答案可能取 A。引用正确，但题目本身存在歧义，建议后续人工确认标准答案。
- q001：模型补充段有一个中间式笔误 `[-3,-3]`，最终结论 `(-∞,-3]∪[3,5)` 正确；不影响引用判定。
- 回答中出现较多“【以下为模型补充，未在你的资料中找到依据】”，说明上下文覆盖不足；这是回答层问题，不是检索 hit@5 能反映的。

## 5. 限制

- 40 条、37 块语料，统计意义有限，不能外推为生产 SLA。
- gold 是 AI 预标注 + 用户抽查，存在选择偏差；hit@5=1.000 只说明“当前流程命中这版 gold”。
- `citation_ok` / `refusal_ok` 是主观逐条判断，不是独立双人标注；本报告完成 AI 初核，并由用户抽查 q001、q010、q014、q021、q028 通过。
- vector 复用混合检索的向量召回再截断，延迟口径偏保守，不是严格隔离的纯向量基准。
- 回答只跑 `hybrid_rerank`；vector/hybrid 没有回答质量数字。
- 在线评测依赖本机服务、真实 Key 和网络；CI 不能完整复现。
- 会话清理是 best-effort；失败可能留下无引用会话。
- `cost_yuan` 以 LLM 返回 usage 为准；失败调用无 usage 时记 0，费用可能偏低。
